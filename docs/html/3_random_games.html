3 Random Games

"3 Random Games" (also written as "3 RANDOM GAMES") is a series of YouTube videos posted by CaptainSauce, starting on November 4, 2018. CaptainSauce plays three small indie games in a single video, ocassionally with a consistent theme between all of them. The videos are generally humorous, with CaptainSauce making jokes and quips while playing them.

While videos originally included the tag "3 RANDOM GAMES - " (2018--19), he switched to the tag " - 3 Random games" (2019--21) before dropping the tag altogether (2021--present).
