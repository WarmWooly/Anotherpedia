Bits & Blocks 1.0.2

{{iBits & Blocks 1.0.2}} is a minor update to the Minecraft mod Bits & Blocks released on July 26, 2026, which added flow worms dropping Flow Worms on death. This update follows 1.0.1 and precedes 1.0.3.
