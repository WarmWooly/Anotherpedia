BOP file (Bits & Bops)

A BOP file (.bop) is a file format for storing custom mixtapes from Bits & Bops. The file itself contains a mixtape.json (holding the mixtape information), a preview.bin (the image file for the mixtape's thumbnail, if included), and a song.bin (the audio file containing the song, if included). Other files can also be stored in a BOP file, such as custom textures used for the mod BopCustomTextures.

BOP files can be directly imported into the game through the jukebox. When a BOP file is imported or downloaded from Steam, it will be unwrapped into a folder with its contents.
