BopVisualEffects

{{iBopVisualEffects}} is an open source Bits & Bops mod created by Brollyy that allows users to add some visual effects into a custom mixtape in the custom mixtape editor. Other users with the mod can then play the mixtapes with these effects. It can be downloaded on GitHub, being a plugin for BepInEx.
