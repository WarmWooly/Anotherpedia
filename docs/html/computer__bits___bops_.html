Computer (Bits & Bops)

The computer is an interactable device in Bits & Bops. It holds access to viewing videos and enabling/disabling the Perfect Tracker. The custom mixtape editor will also be accessed through the computer when complete. It also contains social media links for Bits & Bops. The wallpaper of the computer can be changed. If the firewall is disabled or the disk is formatted, the computer will break and the player will get the Technical Difficulties pin.
