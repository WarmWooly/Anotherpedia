Core

For the suffix, see -core.
For other terms relating to core, see core (disambiguation).
Core is a noun used to describe a central element of something greater than itself, being part of a whole. The core of something tends to be important or structural. Examples of cores are the center of a planet (planetary core) and the inedible center of some fruits. Core can also be used to describe ideas and topics, like the core idea of a work.
