Counting channel

A counting channel is a text channel on Discord or similar platforms where users send messages to continuously count upwards. While called a counting channel, no quantity is actually being counted; rather, each user increments the number by 1 to see if they can reach a goal (such as a specific large number). Common restrictions include requiring that a single user can't increment more than once at a time and that if a user posts the incorrect number, then the count is reset to 1. A dedicated bot can be used to moderate a counting channel to prevent users from cheating. Counting channels can be helpful to gauge how active a server is, as message frequency from users can correlate to users engaging with the server.
