Custom mixtapes (Bits & Bops)

Custom mixtapes are user-generated levels in Bits & Bops, where players create levels similar to mixtapes in the base game using one or more minigames. Custom mixtapes are made in the custom mixtape editor, which is in pre-alpha <>. They can be downloaded from Steam and come as .bop files.
