Data Lens (Snaptic)

Data Lens is a program within the upcoming puzzle-platformer Snaptic used to show invisible text and platforms. It is used by Anon and is saved on the taskbar. It hides normal surfaces, only showing Anon and invisible text/platforms. It can be dragged around and resized like a window, allowing it to be dynamically moved around the screen.
