Game corner (Bits & Bops)

The game corner is a part of the store with additional small levels in Bits & Bops, with the first three cartridges being local multiplayer up to 4 people. The game corner is opened up after the Jungle Mixtape is completed. Each cartridge in the game corner is unlocked after a mixtape is completed, with the cuckoo clock available when the game corner opens. All cartridges are required to be attempted before the player may progress, with all five game corner minigames having an associated pin.<>
