Handle (Bluesky)

A handle on Bluesky is a social media handle that is tied to a domain name. By default, it is @username.bsky.social, with the username selected by the user. Domain names can also be added, which can act as a method of verification through a website owned by the user. It can either be implemented as a TXT record on the DNS or as a text file under https://domain.here/.well-known/atproto-did. This does not impact the display name of the user, and all users can update their handle. While the domain will be the used handle, @username.bsky.social will still remain reserved by that account.
