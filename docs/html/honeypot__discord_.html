Honeypot (Discord)

A honeypot is a text channel on Discord where a bot automatically kicks or bans a user from the server when sending a message to the channel. It is used to curb spam from malicious bots, capturing both bots that join the server and accounts that are hijacked (such as the Discord crypto scam). There are also Discord bots that are dedicated to removing users who message in the honeypot. As normal users shouldn't message in the honeypot, it is an effective way of filtering out bad actors.
