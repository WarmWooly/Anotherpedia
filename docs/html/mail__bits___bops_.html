Mail (Bits & Bops)

The mail is a reward system in Bits & Bops where various rewards are physically shipped to the store, which need to be opened before they are usable. The mail can contain souvenirs, records, videos, pins, and the Perfect Tracker and its update. Bop and Bit will comment on the mail if the pile gets very tall. Each package is opened individually, with souvenirs coming in capsules and displayed on the shelf.
