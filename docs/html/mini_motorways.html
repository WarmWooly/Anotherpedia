Mini Motorways

{{iMini Motorways}} is a 2019 strategy puzzle game released by Dinosaur Polo Club. It features the player connecting a network of houses to destinations using roads to allow traffic to flow efficiently. Only people from the same color house can go to a destination, with each destination slowly accumulating pins that need to be collected. If a player fails to collect the pins from a destination in time, the game ends, with the score being the total number of pins collected. There are many maps based on real-world locations, with the locations of destinations and houses being random in each playthrough.

After each in-game week, a choice between two upgrades will be given to the player, including bridges (to cross water), tunnels (to go through mountains), roundabouts and traffic lights to control traffic, and motorways to cross over structures and to traverse long distances quickly. As the game progresses, destinations will increase their demand, causing the player to continuously reroute and redesign their network to both make it flexible for new houses and destinations while preventing their current network from backing up.
