PNGTuber

A PNGTuber is a VTuber who utilizes multiple sprites instead of a rigged model to represent themselves. The name is derived from the use of PNGs, as it is a popular image file format that supports transparency. For live streaming, the model is usually connected to the creator's audio, causing the model to appear to talk while the creator does. The model may also move around or change based on the expression, either using motion capture or being manually changed. In videos, especially on YouTube, the model is moreso a stand-in for the creator, changing expression to match the tone of the creator.
