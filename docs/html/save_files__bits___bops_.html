Save files (Bits & Bops)

There are three usable save files in Bits & Bops, which are used to store progress. The game is automatically saved whenever something is achieved, such as beating a minigame or mixtape or opening mail. A few interactions will also be saved, such as bricking the computer by disabling the firewall or formatting the disk, with Bit visibly fixing the computer until the save file is reloaded.

The save files are labeled "FILE 1--3", with icons of Bop, Bit, and the canary for each file respectively. Each file will also visibly show how many minigames/mixtapes the player got Cool, Amazing, Perfect, and Diamond Perfect on. Only scores for the normal speed settings will be shown, and custom mixtapes also don't contribute. The total percentage shows the completion of the base game, tallying up getting all Perfects on the normal speed settings and collecting all the Pins. If the player also achieves all Diamond Perfects, then the percentage can total up to 123%.

Save files can be copied into an empty slot, which makes a copy of all the data into the empty slot. Save files can also be erased, permanently deleting all the data associated and freeing up the slot.
