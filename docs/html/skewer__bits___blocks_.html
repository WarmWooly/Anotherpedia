Skewer (Bits & Blocks)

The skewer is a throwable item in the Minecraft mod Bits & Blocks. The skewer can be crafted with 1 Pop-Up Kitchen and 8 sticks (shapeless; makes 16). When used, the skewer will be thrown in the direction the player is facing. If it hits a block, it will drop to the ground. If it hits a mob, it will deal 5 damage (2.5 hearts) and be destroyed. Skewers have an 8 tick cooldown between each throw. Skewers are used in the following crafting recipes:
Frozen Skewer x16 - 8 skewers and 1 Ocean Mixtape (shapeless).
