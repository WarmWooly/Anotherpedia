Status (Discord)

Not to be confused with Activity (Discord).
The status is a visible feature for users on Discord, which comes in two parts: activity and custom status. Activity shows whether the user is online and, in some cases, what they are doing, while custom status is text and/or an emoji that the user can customize. Activity is generally used to denote whether the user is online, which is shown as an icon in the bottom-right of the user's profile picture. The main activity icons are a green circle for online, a yellow moon for idle, a red circle with a dash for do not disturb, and an empty gray circle for offline or invisible. A timer can be set for idle/do not disturb/invisible to automatically revert when it expires. If the user is on a mobile device, then a green phone icon will appear, and if the user is streaming on a connected Twitch or YouTube account, then a purple icon with a triangle will appear. Friends can get notifications when the user comes online or starts streaming, which can be disabled in the settings. Sub-activities show additional information about what the user is doing. This includes playing games which are linked to the user (such as games on Steam; game controller icon), being in a voice channel (speaker icon), and/or participating in an Activity (four shapes icon). It will show up to the left of the custom status, giving additional information when hovered over. This information can be disabled in the settings. The custom status is an optional, customizable status in the form of an emoji and/or a short (128 characters) text. The emoji can be any of the default emojis on Discord, or, with Nitro, any custom emojis. The text can include most (if not all) Unicode characters, including emojis. A timer can be set for when to clear the custom status.
