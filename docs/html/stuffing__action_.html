Stuffing (action)

Stuffing is an action to forcefully put an object into a container or to fill with a solid object. Stuffing can be done to store something, to fill something (like a stuffed toy), or to squeeze something through an opening. When filling an object, stuffing is used to encompass manual insertion without the aid of gravity (unlike filling a container with a loose solid like sand).
