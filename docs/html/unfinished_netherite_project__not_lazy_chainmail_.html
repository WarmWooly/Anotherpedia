Unfinished Netherite Project (Not Lazy Chainmail)

The unfinished netherite project is an item in the Minecraft mod Not Lazy Chainmail used to be snipped into netherite chain links. In a chainmail project with at least 1 netherite chain link added, it can be reset to return all the used chain links in the form of an unfinished netherite project. Unfinished netherite projects can be obtained when a Crusher crushes the following items (storing the listed number of chain links):
Netherite Chainmail Helmet - 320 chain links
Netherite Chainmail Chestplate - 512 chain links
Netherite Chainmail Leggings - 448 chain links
Netherite Chainmail Boots - 256 chain links
Netherite Chainmail Bracelet - 64 chain links
Netherite Chainmail Necklace - 128 chain links
Netherite Chainmail Gloves - 192 chain links
Netherite Chainmail Belt - 128 chain links
Netherite Tool Chain - 192 chain links
Netherite Chainmail Industrial Belt - 256 chain links
Music Disc "Bounce" - 32 chain links Pliers can be used to snip the unfinished project into netherite chain links. The number of chain links in the unfinished project is equal to the number put into the chainmail project before it is reset or the total required for the crushed item. gal
