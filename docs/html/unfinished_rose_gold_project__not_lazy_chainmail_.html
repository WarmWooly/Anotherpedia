Unfinished Rose Gold Project (Not Lazy Chainmail)

The unfinished rose gold project is an item in the Minecraft mod Not Lazy Chainmail used to be snipped into rose gold chain links. In a chainmail project with at least 1 rose gold chain link added, it can be reset to return all the used chain links in the form of an unfinished rose gold project. Unfinished rose gold projects can be obtained when a Crusher crushes the following items (storing the listed number of chain links):
Rose Gold Chainmail Helmet - 320 chain links
Rose Gold Chainmail Chestplate - 512 chain links
Rose Gold Chainmail Leggings - 448 chain links
Rose Gold Chainmail Boots - 256 chain links
Rose Gold Chainmail Bracelet - 64 chain links
Rose Gold Chainmail Necklace - 128 chain links
Rose Gold Chainmail Gloves - 192 chain links
Rose Gold Chainmail Belt - 128 chain links
Rose Gold Tool Chain - 192 chain links
Rose Gold Chainmail Industrial Belt - 256 chain links
Music Disc "Tired" - 32 chain links Pliers can be used to snip the unfinished project into rose gold chain links. The number of chain links in the unfinished project is equal to the number put into the chainmail project before it is reset or the total required for the crushed item.
