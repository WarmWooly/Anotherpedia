Wax Off (Minecraft)

For the achievement in {{aiMinecraft: Bedrock Edition, see Wax on, Wax off (Minecraft).}}
Wax Off is an advancement available on Minecraft: Java Edition that is earned when the player removed honeycomb from a block made of copper using an axe. It is the child of the advancement Wax On. The description is as follows:Scrape Wax off of a Copper block!There are no rewards granted upon completing the advancement.
