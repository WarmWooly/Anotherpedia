Zip (Snaptic)

Zip is a tutorial guide in the demo for the upcoming puzzle-platformer Snaptic. Zip appears as an array of pixelated RGB LEDs on a flat, rectangular body. The top-left corner is separated, which is shown to stretch vertically. Zip talks to Anon, telling him (and the player) information about different mechanics, including camera controls, magnet walls, and the program Data Lens.
